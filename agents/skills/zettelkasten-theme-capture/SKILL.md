# Zettelkasten Theme Capture

Используй этот навык, когда пользователь просит создать Topic, Note или Memo либо зафиксировать тему в `/Users/steamtoad/zettelkasten`.

## Источник правил

Перед созданием документа считай скрипты `/Users/steamtoad/zettelkasten/.scripts/zt-memo.zsh`, `zt-note.zsh`, `zt-keytopic.zsh` и библиотеки `.scripts/lib/` источником истины для формата и побочных эффектов. Если скрипты изменились, следуй новой версии с учетом специальных правил OpenClaw ниже.

## Общие правила

1. Проверь существующие активные документы и не создавай дубль.
2. Создавай UUID v1 core document как `notes/UUID.adoc`.
3. Для документов Марты добавляй `:author: marta` и `:generated-at: YYYY-MM-DD`.
4. Сразу регистрируй новый документ в `all-todays/YYYY-MM-DD.adoc` в формате `* HH.MM - link:../notes/UUID.adoc[Полный заголовок]`.
5. Для связей между core documents внутри `notes/` используй `link:UUID.adoc[Описание]`; контекстные ссылки из `all-todays/` и Workspace формируй через соответствующие helpers скриптов.
6. Находи 2–5 активных документов с сильным смысловым совпадением и добавляй полезные двусторонние ссылки без дублей.
7. Не связывай документы только из-за общего слова и не связывай с deprecated-документами.

## Обычные Memo

Для Memo, не посвященных OpenClaw:

- используй заголовок `Memo - <название> от DD-MM-YYYY`;
- выбери подходящую активную Key Topic;
- добавь `:key-topic:` и двустороннюю связь Memo ↔ Topic;
- связывай Memo с тематически близкими активными Memo.

## Специальное правило для OpenClaw Memo

Memo считается посвященным OpenClaw, если OpenClaw является его главным предметом, а не случайным упоминанием.

Для OpenClaw Memo:

- не добавляй `:key-topic:`;
- не добавляй ссылки на Topic, Note, Todo или Diary;
- связывай его только с другими активными Memo с похожим содержанием;
- добавляй связи двусторонне и проверяй тип каждого целевого документа.

## Специальное правило для OpenClaw Note

Каждую Note, посвященную OpenClaw, обязательно связывай с:

`link:fed2d778-626a-11f1-aa12-c383f7dbaba4.adoc[Open Claw - ключевая тема]`

Для такой Note:

- добавляй `:key-topic: Open Claw`;
- добавляй в Note ссылку на Topic;
- добавляй в Topic обратную ссылку на Note в секцию `== Связанные note`;
- связывай Note двусторонне с близкими активными Note и Topic, когда связь содержательна.

## Создание Topic

Для новой Topic:

- используй заголовок `<название> - ключевая тема`;
- добавляй `:type: topic` и `:key-topic: <название>`;
- связывай Topic двусторонне с близкими активными Topic и Note;
- не добавляй OpenClaw Memo в Topic `Open Claw`.

## Проверка после создания

Всегда проверь:

- обязательные метаданные и тип документа;
- наличие записи в сегодняшнем `all-todays`;
- двусторонние связи;
- для OpenClaw Note — связь с Topic `Open Claw`;
- для OpenClaw Memo — отсутствие ссылок на документы типов, отличных от Memo;
- существование всех относительных ссылок;
- `.scripts/zt-check.zsh` и `git diff --check`.

В итоговом ответе перечисли созданные документы, Topic, кросс-ссылки и результаты проверок.
