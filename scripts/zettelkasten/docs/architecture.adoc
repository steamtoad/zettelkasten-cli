= Zettelkasten как плагин основного движка
:revdate: 2026-09-06
:toc:

== Роль плагина

Основной движок умеет создавать валидные AsciiDoc-объекты и предоставляет
нейтральные операции над путями, UUID, metadata и ссылками. Плагин Zettelkasten
превращает эти примитивы в пользовательский workflow личной базы знаний.

== Структура

[source,text]
----
scripts/
├── lib/                    # paths, uuid, asciidoc: neutral engine
├── objects/                # Note, Memo, Topic, Todo, Diary constructors
├── zettelkasten/            # Note, Memo, Topic, Todo workflows
│   ├── lib/                # bindings.zsh, today.zsh
│   └── docs/
├── diary/
│   ├── zt-diary.zsh
│   ├── lib/today.zsh
│   └── docs/
├── inbox/
│   ├── capture.zsh
│   ├── processed.zsh
│   └── docs/
├── workspace/
│   ├── zt-workspace-{create,add,open,remove}.zsh
│   ├── lib/workspace.zsh
│   └── docs/
└── zt-*.zsh                # host CLI and compatibility entrypoints
----

== Поток создания

[source,text]
----
compatibility entrypoint
  -> plugin workflow
     -> engine constructor
        -> neutral lib
     -> plugin policy: binding / today
     -> editor + output link
----

== Публичная граница движка

Плагин использует функции `zk_*` из `lib/` и `objects/`. Собственные функции
policy имеют prefix `zt_*`. Временные переменные библиотек не должны попадать в
namespace подключающего скрипта.

== Текущая граница миграции

Zettelkasten plugin содержит четыре creation workflow и две policy library.
Diary, Inbox и Workspace принадлежат отдельным sibling plugins. Continue,
Reduce и Refine временно используют Zettelkasten `today.zsh`, а Continue также
`bindings.zsh`. Workspace больше не использует Zettelkasten policy.

Diary зависит от neutral `objects/`, `lib/` и собственного кода. Inbox и
Workspace зависят от `lib/` и собственного кода. Между sibling plugins нет
source dependencies; `lib/` и `objects/` не зависят от plugins.
Собственные helpers Diary используют prefix `dp_*`; общий формат `all-todays`
проверяется behavioral regression suite без взаимного source.

[source,text]
----
host CLI -> objects / lib / plugin entrypoints
host CLI -> plugin/lib  # transitional dependency
----
