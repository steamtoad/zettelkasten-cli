= Feature List плагина Zettelkasten
:revdate: 2026-08-29
:revnumber: 3
:toc:

== Назначение

Здесь перечислены только возможности, реализованные внутри
`scripts/zettelkasten/`.

== Creation workflow

* `ZP-FEATURE-001` — интерактивное создание Note.
* `ZP-FEATURE-002` — интерактивное создание датированного Memo.
* `ZP-FEATURE-003` — интерактивное создание Topic.
* `ZP-FEATURE-004` — интерактивное создание датированного Todo.
* `ZP-FEATURE-006` — регистрация каждого успешно созданного объекта в `all-todays`.
* `ZP-FEATURE-007` — открытие созданного документа в Vim и вывод ссылки.

== Binding policy

* `ZP-FEATURE-010` — опциональная связь Topic -> Memo.
* `ZP-FEATURE-011` — опциональная связь Memo -> Note.
* `ZP-FEATURE-012` — выбор active target через `fzf`.
* `ZP-FEATURE-013` — inheritance `key-topic` и keywords.
* `ZP-FEATURE-014` — двусторонние ссылки parent/child.
* `ZP-FEATURE-015` — Topic без непустого header `:key-topic:` не предлагается для Memo binding; повторная defensive-проверка выполняется до создания Memo.

== Policy libraries

* `ZP-FEATURE-020` — `today.zsh` регистрирует Note, Memo, Topic и Todo в `all-todays`; Diary использует собственный helper с тем же форматом.
* `ZP-FEATURE-021` — `bindings.zsh` владеет выбором и наследованием связей.

== Compatibility

* `ZP-FEATURE-030` — четыре прежних top-level creation entrypoints делегируют плагину без изменения пользовательских команд.

== Не входит в текущий плагин

Diary, Inbox и Workspace реализованы в отдельных sibling plugins.
Поиск, Read, Check, Continue, Reduce, Refine,
публикация и skills tooling пока реализованы как host CLI. Они не заявлены как
plugin features, даже если работают с данными Zettelkasten.
