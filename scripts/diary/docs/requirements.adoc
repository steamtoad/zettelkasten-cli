= Diary plugin: требования
:revdate: 2026-09-06
:toc:

Нормативный baseline: `openspec/specs/`. Здесь сохранены stable IDs и статусы.

== Diary

* `ZP-DIARY-001 [IMPLEMENTED]` — Diary создаётся через neutral Diary constructor.
* `ZP-DIARY-002 [IMPLEMENTED]` — `.last-diary` хранит basename последней записи.
* `ZP-DIARY-003 [IMPLEMENTED]` — новая и предыдущая записи соединяются двунаправленно.
* `ZP-DIARY-004 [INVARIANT]` — значение `.last-diary` с разделителем пути отклоняется.
* `ZP-DIARY-005 [INVARIANT]` — state обновляется только после успешного создания и связывания.

== Архитектура и совместимость

* `DP-ARCH-001 [IMPLEMENTED]` — Zettelkasten-CLI SHALL размещать канонический Diary workflow, Diary chain/state policy и plugin-specific документацию в sibling plugin `scripts/diary/` внутри репозитория `zettelkasten-cli`; Diary workflow MUST оставаться вне ownership `scripts/zettelkasten/`.
* `DP-ARCH-002 [INVARIANT]` — Diary plugin MUST depend only on its own plugin-specific code, `scripts/objects/` и domain-neutral primitives under `scripts/lib/`. Diary plugin MUST NOT depend on `scripts/zettelkasten/`; `scripts/lib/`, `scripts/objects/`, `scripts/zettelkasten/` и другие sibling plugins MUST NOT depend on `scripts/diary/`.
* `DP-COMPAT-001 [IMPLEMENTED]` — `scripts/zt-diary.zsh` SHALL оставаться публичным compatibility entrypoint, делегировать каноническому workflow Diary plugin и сохранять существующие CLI arguments, stdout/stderr, exit status, editor invocation и managed skill mapping.
* `DP-DATA-001 [INVARIANT]` — Выделение Diary plugin MUST preserve создание Diary через neutral constructor, размещение в `notes/`, UUID/AsciiDoc metadata, canonical links, bidirectional Diary chain, basename state в `ZK_HOME/.last-diary` и регистрацию в `all-todays`. Оно MUST NOT перемещать, переписывать или переиндексировать существующие пользовательские Diary и state.
* `DP-DEV-001 [PROCESS]` — Изменения Diary plugin MUST сопровождаться regression verification через `scripts/zt-diary.zsh` с временным `ZK_HOME`; ordinary development и validation MUST NOT mutate пользовательские `notes/`, `all-todays/` или `.last-diary`.
